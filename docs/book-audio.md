# Аудио книги

Для формата `book.json`, полей `AudioEffect`, значений по умолчанию и JSON-примеров см. [авторский контракт](https://github.com/KrimsonKing1337/active-book-types/blob/main/docs/audio-effects.md).

## Активация и готовность

`AppWrapper.audioDescriptions` и `App.audioDescriptions` принимают полный список `AudioEffect<number>` после сборки. Позиции начинаются с 1. `BookSession` создаёт `BookAudio` на время открытия книги. Владелец публикует экземпляры по `id`, пока их область действия включает текущую страницу. Один файл можно использовать в нескольких эффектах с независимыми экземплярами. ID декларативных эффектов зарезервированы для всей сессии книги.

Движок объединяет соседние и перекрывающиеся интервалы одного описания. Переход внутри непрерывного интервала сохраняет экземпляр и позицию. Прямой вход в середину диапазона создаёт экземпляр для этой активации. Выход и повторный вход после освобождения создают новую активацию. Разные эффекты могут звучать одновременно на пересечении диапазонов.

В reader новые активные ресурсы регистрируются при подготовке страницы. Ошибка загрузки завершает ожидание этого ресурса и позволяет раскрыть страницу. Уже играющий звук может продолжаться во время подготовки следующей страницы, если он активен и там. Закрытие и смена книги отменяют подготовку и освобождают активные и уходящие экземпляры.

## Временная шкала

`t₀` — момент первого фактического раскрытия страницы для конкретной активации. Переход внутри диапазона и быстрое восстановление ещё играющего экземпляра сохраняют `t₀`.

- `playOnLoad` запрашивает один автозапуск. `delay` откладывает его до `t₀ + delay`. Браузер также должен разрешить воспроизведение.
- Если разрешение приходит после `delay`, звук может начаться сразу, пока дедлайн ещё действует. Обычно reader получает разрешение от доверенного жеста пользователя. Режим editor загружает ресурс для предпрослушивания, которое запускается вручную.
- `stopBy > 0` задаёт одноразовую остановку в `t₀ + stopBy`. При `delay >= stopBy` автозапуска нет. После автоматической остановки активный эффект доступен для ручного запуска.
- Ручная команда отменяет ожидающий автозапуск. При выходе из области действия откладываемый автозапуск также отменяется.

## Затухание и микшер

`fadeIn` определяет плавное появление при автозапуске. `fadeOut` определяет затухание при остановке по `stopBy` или обычном выходе из области действия. Если активен `waitTillTheEnd` и дедлайн ещё не наступил, выход позволяет закончить текущую итерацию. Для зацикленного звука движок отключает повтор. При быстром возврате может восстановиться исходный цикл.

При выходе эффект сразу становится недоступен через контроллер по ID. Обычное затухание можно обратить, пока экземпляр ещё играет. Ручная пауза и остановка сохраняют своё намерение при возврате.

Одновременно затухают до двух поколений. При появлении нового поколения оставшееся время уже уходящего сокращается до 100 мс или сохраняется, если оно меньше. Сокращение начинается с текущего коэффициента. При появлении третьего поколения самое старое завершается немедленно. Ожидание естественного окончания учитывается отдельно. Завершение обработчиков и освобождение в реальном браузере зависят от того, когда выполняются таймеры и очереди событий.

Громкость складывается из глобального, категорийного (`bg`, `music`, `sfx`) и относительного коэффициентов, умноженных на текущий коэффициент плавности. Изменения микшера применяются и к уходящим звукам. Корректировка громкости сохраняет движение по текущему fade и его дедлайн.

## Контроллер и наблюдение за загрузкой

`useAudioController(id)` из `@active-book/core/hooks/effects` возвращает `audio` для доступного экземпляра и команды `play(withFadeIn?)`, `pause(withFadeOut?)`, `stop(withFadeOut?)`, `remove()`. По умолчанию ручные команды работают без плавности. `pause` сохраняет позицию, `stop` сбрасывает её. `remove` снимает регистрацию и запускает освобождение экземпляра. При отсутствии экземпляра ручные команды ничего не запускают.

У `audio` доступны, например, `playing()`, `howlInst.seek()` для чтения позиции и `volume(categoryVolume)`. Последний метод принимает категорийный коэффициент от 0 до 1 для этого экземпляра. Для изменения всей группы используйте настройки микшера.

`audio.observeLoad(listener)` сообщает `ready`, `failed` или `cancelled`. Для ещё загружающегося экземпляра возвращается функция отписки. Известный результат передаётся сразу при подписке. При подписке на освобождённый экземпляр приходит `cancelled`. Результат самой загрузки можно прочитать через `audio.loadOutcome`. Снимайте подписку при смене экземпляра или размонтировании.

`Audio` и `useAudio()` создают императивный экземпляр с явно заданными владельцем временем жизни и командами. В режиме `lifecycle: 'auto'` экземпляр освобождается при уходе со страницы или размонтировании. В режиме `lifecycle: 'manual'` владелец вызывает `remove()`. Декларативные описания обслуживаются `BookAudio` по области действия и шкале раскрытия страницы.
